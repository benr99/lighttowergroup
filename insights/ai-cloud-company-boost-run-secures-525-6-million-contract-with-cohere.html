AI cloud company Boost Run secures $525.6 million contract with Cohere

Boost Run has secured a $525.6 million cloud contract with Cohere for dedicated GPU cloud computing infrastructure, with terms running approximately five years

Ben Rohr October 08, 2026 1 min read 1 source
Share LinkedIn X / Twitter

AI cloud provider Boost Run has secured a $525.6 million cloud contract with Cohere, the Canadian AI startup. Under the agreement, Cohere will lease access to Boost Run's dedicated GPU cloud computing infrastructure and related services. The term for each rack provided is set to run for approximately five years, and a portion of the contract value is prepayable. Cohere is expected to begin accepting the infrastructure in the second quarter of 2027, at which point the term of the agreement will start.

Boost Run was founded in 2024 and, according to an SEC filing, owns and operates bare-metal GPU servers within top-tier data centers used to run AI and HPC workloads. As of the end of 2025, it operated out of four TierPoint data centers in Seattle, Durham, Dallas, and Richardson, Texas. In its most recent 10Q filing, covering the six months ending June 30, 2026, Boost Run reported revenues of $31.14 million, up from $8.423 million the year prior, and an operating loss of $12.9 million. Total colocation lease cost was $10.56 million, a year-over-year increase of 576 percent. Cohere has previously signed a $220 million cloud agreement with Buzz HPC for capacity at its Merritt, British Columbia, data center.

The contract provides a meaningful revenue anchor for Boost Run, which is still operating at a loss, and signals continued demand for dedicated GPU infrastructure from AI model developers. The agreement also contains a termination mechanism: if Boost Run has not provided a minimum amount of infrastructure by July 15, 2027, Cohere can terminate the agreement and receive a refund of all amounts prepaid. This creates a delivery risk for Boost Run as it expands its colocation footprint.

Details about which data centers the agreement will apply to have not been shared. It is also unclear whether Boost Run's recent colocation leases are exclusively with TierPoint, and the source does not specify the total capacity or GPU types involved in the Cohere contract. The financial impact beyond the headline contract value remains unknown.
